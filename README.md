# World Pickle Map

An interactive globe and regional China map exploring pickled vegetables around the world.

Drag the globe to rotate. Hover over stars to preview a food, or click a star to read its full story. On mobile, tap a star. Select China to explore the regional map and catalog.

## Build

No JavaScript dependencies or build service are required to serve this static site. Open `index.html` or publish the repository root with GitHub Pages.

To regenerate the page after changing its template or food data:

```sh
python3 工作文件/build2.py
```
